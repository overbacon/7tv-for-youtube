The global 7TV set (~45 emotes) loads automatically. 7TV has no single "everything" library — popular emotes like OMEGALUL or KEKW live inside specific channels' sets. Add their IDs below to pull those in too.

On 7tv.app, open the channel/profile → click their active emote set (opens a page whose URL contains /emote-sets/) → paste that link here. A plain profile link (/users/...) won't work — it has to be the set's own page. Put your own set last so its names win if they clash with an earlier one. Reload the YouTube chat tab after saving.
